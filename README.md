# ZIP

**가격만으로는 보이지 않는 동네.**

관악구의 신고 가격·건물·지형을 같은 지도에서 읽고, 사용자 중요도로 장소를 비교하는 개발 중 서비스 ZIP의 소개 페이지입니다. 현재 제품 코드와 최신 기획을 확인해 설명용 모형, 실제 개발 화면, 후속 계획을 구분합니다.

밝은 건축 모형 스튜디오를 배경으로, 가상 동네에서 한 장소로 다가가 여덟 장면에 걸쳐 살펴봅니다. 발견 → 가격 → 생활 조건 → 내 기준 → 세 장소 비교 → 가격 환산 → 자료의 한계 → 실제 개발 화면으로 이어집니다. 소개용 3D 지도는 도로·교차로·보행 공간·공원, 형태와 높이가 다른 주변 건물 6개와 중심 건물 A로 설계했습니다. A는 깊은 창, 청동 프레임, 발코니, 중정과 옥상 정원을 갖춘 개념 조형물입니다. 실제 건물의 구조나 지형을 재현하지 않습니다.

장면마다 정보와 모형의 구도가 달라집니다. 가격은 큰 숫자와 세 가지 임대 조건, 생활 조건은 세 지표, 중요도는 비율과 점수 변화, 비교는 A/B/C 모형과 같은 열의 표로 읽습니다. 가격 환산은 같은 0축의 가로 막대와 계산 근거를 보여 줍니다. 마지막에는 자료가 없는 X를 분리해 설명합니다.

이어지는 제품 소개는 2026년 11월 13일 로컬 ZipDev에서 캡처한 실제 개발 화면입니다. 같은 관악드림타운과 카메라를 유지하며 지도 → 내 기준 → 시간 → 깊이 보기로 이어집니다. 데스크톱에서는 하나의 고정된 화면이 스크롤에 따라 바뀌고, 모바일에서는 읽을 부분을 확대해 원본 링크와 함께 제공합니다. 현재 기능과 교통·생활·인구·상권·환경·모바일 UX의 후속 계획을 구분합니다. 제품 캡처는 실시간 지도나 공개 앱 연결을 대신하지 않습니다.

카메라·동네에서 장소로의 접근·모형의 배치·색·수치·텍스트는 하나의 진행값을 공유합니다. 스크롤 입력은 90ms 공통 clock으로 부드럽게 연결하고, 정지하면 렌더링도 멈춥니다. 제목·설명·근거가 순차적으로 나타나며 읽기 구간에서는 정착합니다. 하단 탐색은 별도의 grid 행을 차지하고, 진행선은 상단에 하나만 둡니다. 좁은 화면에서는 설명 위 / 모형 가운데 / 정보 아래의 구도로 바뀝니다.

본문은 조작 없이 끝까지 이해할 수 있습니다. 중요도는 균등 → 경사 80%·고도 10%·연식 10%로 자동 시연하며 가격은 그대로입니다. 별도 체험창에는 기존의 24개 가상 장소 지도를 유지합니다. 방문자의 중요도·선택·담은 장소·공유 URL은 소개 시연과 독립적이며, 창을 닫으면 보던 위치로 돌아갑니다.

움직임 줄이기 설정에서는 완성된 정지 장면을 제공합니다. 높이 620px 이하 화면, 높이 700px 이하의 좁은 휴대폰 화면, 스크립트가 없는 환경은 여덟 장을 일반 문서 흐름으로 읽습니다. 작은 화면에서 모형을 정보 뒤에 자르는 대신 각 장면의 그림과 정보를 온전히 보여 줍니다. WebGL을 사용할 수 없을 때는 같은 아틀리에 컨셉의 SVG 모형을 표시합니다. 장식용 곡선 연결선과 색상 받침판은 제거했습니다. 색 범례는 내 기준 점수를 설명하는 장면에서만 표시합니다.

공개 페이지: https://yebyeol.github.io/ZipLanding/

이 저장소는 정적 소개 웹사이트입니다. 도시 모형과 24곳 체험 값은 가상 예시입니다. 별도로 표시한 실제 개발 화면만 관악구 자료를 사용하며, 현재 매물이나 완성된 공개 서비스를 뜻하지 않습니다.

## 로컬 실행

Node 22 이상과 Python 3을 사용합니다. 앱 의존성 설치는 필요하지 않습니다.

```sh
npm run dev
# http://127.0.0.1:4178
npm test
npm run check
```

Three.js 0.187.0의 공식 브라우저 모듈 두 개를 `vendor/`에 고정해 제공합니다. 런타임 CDN은 사용하지 않습니다. WebGL 2를 사용할 수 없으면 SVG 대체 모형과 비교 기능을 유지합니다.

ES modules를 사용하므로 로컬 HTTP 서버로 열어주세요. GitHub Pages에서는 그대로 동작합니다.

## 구성

- `index.html`, `styles.css`, `styles/film.css`: 소개, 반응형 화면, 모션과 스크립트 없는 읽기 경로
- `styles/demo-polish.css`: 선택 체험창에만 적용하는 제품 인터페이스
- `scripts/demo.mjs`: 24개 가상 건물, 조건 점수, 가격 비교, 공유 URL 검증
- `scripts/city.mjs`: SVG 대체 모형과 3D가 공유하는 색 계산
- `scripts/scene3d.mjs`, `scene-model.mjs`: 건축 모형 3D, 이름표·건물 선택, 사선·내려다보기·선택 확대, 카메라 범위와 그래픽 대체
- `scripts/scene-formation.mjs`, `scene-framing.mjs`: 장면별 모형 배치·카메라 구도와 투영 계산
- `scripts/atelier-svg.mjs`: 소개용 SVG 대체 모형과 정지 그림 생성
- `scripts/story-timeline.mjs`, `film-model.mjs`, `story.mjs`: 여덟 장의 동작·읽기 정지·연속 전환과 자동 시연의 실제 계산 snapshot
- `scripts/atelier-architecture.mjs`: 공식 RoundedBoxGeometry로 설계한 건축 요소, 물리 재질과 스튜디오 환경 조명
- `scripts/atelier-neighborhood.mjs`: 도로·공원·주변 건물의 공통 설계, Three 인스턴스와 SVG 대체 그림
- `scripts/motion.mjs`: 한 프레임에 모은 스크롤 연출, 읽기 진행, 현재 메뉴와 움직임 줄이기
- `scripts/product-tour.mjs`: 같은 스크롤 스케줄러에 연결한 네 개발 화면의 연속 전환과 본문 등장
- `scripts/main.mjs`: 중요도·지도 선택·담기·비교·공유 연결
- `assets/`: SVG 브랜드·도시 장면, 실제 개발 화면 WebP, 공유 이미지, 로컬 글꼴
- `tests/`: Node 기본 테스트
- `docs/verification.md`: 실제 확인 범위와 제한
- `docs/research/3d-skills-and-prompts.md`: 검토한 3D 스킬·프롬프트 자료와 적용 근거
- `docs/research/2026-11-13-zipdev-product-audit.md`, `2026-11-13-zipdev-implementation-audit.md`: 현재 기획과 실제 구현의 대조
- `docs/research/2026-11-13-landing-reference-study.md`: 공식 3D·스크롤 랜딩 레퍼런스, 무료 라이브러리와 스킬 검토

## 체험 계산

경사·고도·연식을 예시 집합의 순위로 바꾸고 중요도에 따라 가중 평균합니다. 가격은 점수에 포함하지 않으며, 자료 없는 조건은 빼고 다시 나눕니다. 중요도가 모두 0이면 동일 중요도를 적용합니다.

월 환산 단가 = `(월세 + 보증금 × 0.05 ÷ 12) ÷ 면적`. 연 5%는 체험용 가정이며 관리비는 제외합니다. 점수가 ±5점인 예시끼리 비교하며, 비교 대상이 5개 미만이면 퍼센트 요약을 표시하지 않습니다. 실제 지역의 저평가·고평가를 판단하는 계산이 아닙니다.

## 자산과 출처

로고와 도시 모형은 이 페이지를 위해 직접 만든 자산입니다. 공공 건물 도형·거래 원자료를 배포하지 않으며, `assets/product/`에는 로컬 개발 앱의 화면 캡처만 포함합니다. 촬영 상태, 가공 범위와 화면 속 자료 표기는 [캡처 기록](docs/research/2026-11-13-product-captures.md)에 기록했습니다.

3D 엔진은 [Three.js 0.187.0](https://github.com/mrdoob/three.js/releases/tag/r187)입니다. 공식 npm 배포본과 같은 두 모듈을 포함하며 MIT 라이선스 전문은 `vendor/THREE-LICENSE.txt`에 있습니다. 같은 r187의 공식 RoundedBoxGeometry·RoomEnvironment addon을 로컬 제공하고, PMREM으로 스튜디오 반사광을 한 번 생성합니다. 무료 모델팩과 재질 비교 및 출처는 [리소스 검토](docs/research/2026-11-13-sculpture-resources.md)에 기록했습니다.

Pretendard Variable은 [Pretendard 공식 저장소](https://github.com/orioncactus/pretendard)에서 받아 로컬 제공합니다. SIL Open Font License 1.1 전문은 `assets/fonts/OFL.txt`에 포함되어 있습니다.

## 배포

`main`에 push하면 GitHub Actions가 테스트·문법 검사를 수행하고 HTML·기본 CSS·styles·scripts·assets·vendor만 Pages 아티팩트로 만듭니다. JS와 모듈 에셋은 콘텐츠 해시별 runtime 경로에서 제공하고, CSS와 HTML의 이미지·글꼴 참조도 버전 처리합니다. 새 문서를 열 때 이전 JS·CSS가 섞이지 않도록 구성했습니다. 개발 기록·테스트·문서·로컬 설정은 웹 아티팩트에 포함하지 않습니다. API, 계정, 서버 또는 인증키는 필요하지 않습니다.
