# ZIP

**도시를 보는, 나만의 기준.**

장소의 조건을 사용자 중요도로 종합하고 비슷한 조건의 장소와 가격을 비교하는 지도 플랫폼, ZIP의 소개 페이지입니다.

본문 전체를 스크롤로 재생하는 여덟 장의 이야기로 구성합니다. 도시의 발견→가격표→조건→중요도 자동 시연→세 장소 비교→가격 환산→자료의 한계→마무리까지 같은 도시를 따라갑니다. 카메라·색·중요도 막대·계산 점수·비교표·공식·선이 하나의 부드러운 진행값을 따르며, 완성된 장면에는 멈춰 읽는 구간을 둡니다. 도시 화면의 위치와 크기는 장마다 바뀌지 않습니다.

본문은 직접 조작하지 않아도 끝까지 이해할 수 있습니다. 중요도는 균등→경사80%·고도10%·연식10%로 자동 시연하며 가격은 그대로입니다. 방문자의 직접 체험은 별도 창에서 열고, 중요도·선택·담은 장소·공유 URL은 이야기와 독립적으로 유지합니다. 창을 닫으면 보던 위치로 돌아갑니다. 움직임 줄이기는 정지 시점과 완성된 그래픽으로, 낮은 화면이나 스크립트가 없는 환경은 여덟 장의 일반 문서 흐름으로 읽습니다.

가격·조건·자료 없음의 단일 장소 표지만 실제3D/SVG 투영 좌표의 선으로 연결합니다. 비교·중요도·가격 그래프는 같은 장소 식별자와 실제 도시 강조로 연결하고 긴 분기선을 없앴습니다. 가려지거나 화면 밖에 있는 표지의 선은 숨깁니다. 가격은 같은0 기준축으로 비교하며 모바일에서도 세 생활 지표와 비교표를 읽고 장면 선택기로 마지막까지 이동할 수 있습니다.

도시는 하나의 full-stage canvas를 크게 사용합니다. 설명과 정보 패널은 같은 읽기 영역의 문서 흐름에 순서대로 놓고, 하단 탐색에는 별도 grid 행을 확보합니다. 이전·장면 선택·다음을 한곳에 모으며 진행선은 상단에 하나만 표시합니다. 내용이 화면보다 길면 읽기 영역 안에서 키보드로도 스크롤할 수 있고, 연결선은 실제 보이는 정보만 따라갑니다.

장면별 확대·회전·관심 위치를 연출하며 화면 가장자리의 오브제 crop은 의도적으로 허용합니다. 전체 도시를 작은 사각형에 맞추는 fit은 소개에 사용하지 않습니다. 스크롤 입력은90ms 공통 clock을 거쳐 텍스트·수치·색·카메라에 함께 적용하고, 정지하면 애니메이션 프레임도 멈춥니다. 제목→설명→근거가 같은 카메라 전환 안에서 순차적으로 등장하고 읽기 구간 전에 정착합니다. 가격은 밝은 명세서의 큰 숫자로, 생활 조건은 나란한 세 지표로, 중요도는 비율과 결과로, 비교는 같은 열에 정렬한 표로 읽습니다. 좁은 화면에서는 근거 그래픽 아래에 불투명한 읽기 배경을 확보합니다. 환산은1.70만/㎡ 결과·같은0축 가로 비교·월 환산 비용39.17만과 계산 근거 순서로 설명합니다.

도시의 파라펫·지붕 설비·창·입면·가로 시설을 반복 인스턴스로 구성하고 장면에 참여하는 장소 이름표만 강조합니다. 체험 지도에서는 모든 장소 이름표를 유지합니다. 글자 확대 시 중앙 정렬 때문에 첫 문장이 화면 위로 사라지지 않도록 안전한 정렬과 내부 스크롤을 함께 사용합니다.

공개 페이지: https://yebyeol.github.io/ZipLanding/

이 저장소는 서비스 컨셉을 소개하는 정적 웹사이트입니다. 도시 모형과 모든 체험 값은 직접 만든 가상 예시이며 실제 관악구 건물, 지역 가격, 현재 매물이나 완성된 서비스를 나타내지 않습니다.

## 로컬 실행

Node 22 이상과 Python 3을 사용합니다. 앱 의존성 설치는 필요하지 않습니다.

```sh
npm run dev
# http://127.0.0.1:4178
npm test
npm run check
```

Three.js 0.187.0의 공식 브라우저 모듈 두 개를 `vendor/`에 고정해 제공합니다. 런타임 CDN은 사용하지 않습니다. WebGL 2를 사용할 수 없으면 기존 SVG 모형과 비교 기능을 유지합니다.

ES modules를 사용하므로 로컬 HTTP 서버로 열어주세요. GitHub Pages에서는 그대로 동작합니다.

## 구성

- `index.html`, `styles.css`, `styles/film.css`: 소개, 반응형 화면, 모션과 스크립트 없는 읽기 경로
- `styles/demo-polish.css`: 선택 체험창에만 적용하는 제품 인터페이스
- `scripts/demo.mjs`: 24개 가상 건물, 조건 점수, 가격 비교, 공유 URL 검증
- `scripts/city.mjs`: SVG 대체 모형과 3D가 공유하는 색 계산
- `scripts/scene3d.mjs`, `scene-model.mjs`: 건축 모형 3D, 이름표·건물 선택, 사선·내려다보기·선택 확대, 카메라 범위와 그래픽 대체
- `scripts/scene-framing.mjs`: 소개 구도의 off-axis 배치와 선택적인 geometry fit API
- `scripts/story-timeline.mjs`, `film-model.mjs`, `story.mjs`: 여덟 장의 동작·읽기 정지·연속 전환과 자동 시연의 실제 계산 snapshot
- `scripts/story-connections.mjs`: 실제 건물 표지와 데이터의 투영 연결, 가림/클리핑 처리
- `scripts/motion.mjs`: 한 프레임에 모은 스크롤 연출, 읽기 진행, 현재 메뉴와 움직임 줄이기
- `scripts/main.mjs`: 중요도·지도 선택·담기·비교·공유 연결
- `assets/`: SVG 브랜드·도시 장면, 공유 이미지, 로컬 글꼴
- `tests/`: Node 기본 테스트
- `docs/verification.md`: 실제 확인 범위와 제한
- `docs/research/3d-skills-and-prompts.md`: 검토한 3D 스킬·프롬프트 자료와 적용 근거

## 체험 계산

경사·고도·연식을 예시 집합의 순위로 바꾸고 중요도에 따라 가중 평균합니다. 가격은 점수에 포함하지 않으며, 자료 없는 조건은 빼고 다시 나눕니다. 중요도가 모두 0이면 동일 중요도를 적용합니다.

월 환산 단가 = `(월세 + 보증금 × 0.05 ÷ 12) ÷ 면적`. 연 5%는 체험용 가정이며 관리비는 제외합니다. 점수가 ±5점인 예시끼리 비교하며, 비교 대상이 5개 미만이면 퍼센트 요약을 표시하지 않습니다. 실제 지역의 저평가·고평가를 판단하는 계산이 아닙니다.

`main`에 push하면 GitHub Actions가 테스트·문법 검사를 수행하고 HTML·기본 CSS·styles·scripts·assets·vendor만 Pages 아티팩트로 만듭니다. 개발 기록·테스트·문서·로컬 설정은 웹 아티팩트에 포함하지 않습니다. API, 계정, 서버 또는 인증키는 필요하지 않습니다.
