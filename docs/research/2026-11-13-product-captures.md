# 실제 개발 화면 캡처 기록

- 촬영일: 2026-11-13, 로컬 ZipDev `http://localhost:5174/`.
- 구현 확인 기준: ZipDev `zip-foundation`, HEAD `98c05b3`. 작업 중인 저장소는 읽기만 했으며 원본 파일·서버 설정을 변경하지 않았다.
- 네 장면 모두 관악드림타운 선택, 같은 중심·각도·확대 유지. 1440 × 1000 화면을 WebP로 저장했다.
- 카메라: 경도 126.94941, 위도 37.48904, zoom 16.5, pitch 55, bearing -20. 내부 선택 ID `b14721`.
- 사진처럼 렌더링한 가상 앱 화면이 아니라 실제 로컬 앱 동작을 캡처했다. 공개 운영 앱, 현재 매물, 실시간 데이터로 소개하지 않는다.

| 파일 | 관찰 상태 | 모바일 상세 이미지 |
|---|---|---|
| `map.webp` | 월세 가격 지도, 선택한 장소의 가격·건물 정보 | 원본 (1084,70)–(1424,635) 상세 패널 |

원본 WebP 품질 90, 상세 자르기 품질 94. 상세 이미지는 `*-detail.webp`이며 UI 수치·문구를 합성하거나 바꾸지 않았다. HTML에도 설명과 전체 이미지 링크를 제공한다. 익명 로컬 브라우저 세션을 사용했고 촬영 후 종료했다. ZIP 계정, 개인 설정 또는 비공개 사용자 자료는 포함하지 않았다.

화면 속 가격 요약은 신고 계약과 지정된 집계 기간을 뜻한다. 시간 막대는 월 단위로 이동하는 6개월 구간이며 같은 집의 반복 매매 지수는 아니다. 상세 패널의 최근 12개월 요약과 구분해 읽어야 한다. 연 5% 환산은 제품·체험의 가정이며 관리비를 포함하지 않는다. 개발 중 데이터와 표시 방식은 이후 달라질 수 있다.

화면 속 지도·자료에는 서울특별시, 국토교통부, 국가데이터처, OpenStreetMap contributors 표기가 있다. 랜딩의 제품 구간에도 출처 표기를 둔다. 이것은 원자료 재배포 또는 별도의 라이선스 권리를 주장하는 문서가 아니다. 런타임 3D 엔진·글꼴 라이선스는 기존 `vendor/THREE-LICENSE.txt`, `assets/fonts/OFL.txt`에 보존했다.
