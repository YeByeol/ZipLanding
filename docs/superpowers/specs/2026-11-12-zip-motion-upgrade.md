# ZIP 스크롤·3D 상호작용 고도화

사용자 요청: 기존 랜딩에 스크롤 상호작용, 3D 디자인·동작, 적절한 효과를 적용해 고도화한다. 기존 승인 디자인의 도시 모형·브랜드·정보 구조·예시 계산은 이어간다.

## 선택한 접근

SVG를 기울이는 가벼운 방식과 실제 3D 장면을 비교했다. 사용자가 요청한 회전·깊이·선택 동작을 위해 **Three.js의 실제 WebGL 도시 모형**을 선택한다. 기존 SVG는 지원하지 않는 환경과 로딩 중 대체 화면으로 재사용한다. 새로운 시각 방향이나 제품 기능을 여는 작업이 아니라 이미 승인된 소개·체험의 표현과 조작을 구체화하는 후속 개선이다.

## 동작

- 첫 화면: 입체 도시의 실제 재질·면·빛·그림자, 짧은 등장. 자연스럽게 스크롤하면 카메라가 부드럽게 시점을 바꾼다.
- 플랫폼: 드래그 회전, 건물 선택, 색 주제 전환이 연결된다. 회전 버튼·처음 시점 버튼으로 마우스 드래그 없이도 쓸 수 있다.
- 내 기준: 기존 중요도와 비교 상태를 그대로 사용하고, 새 3D 건물이 현재 점수 색으로 바뀐다. 선택·hover 강조와 A~X의 고정 식별자를 유지한다.
- 스크롤: 내용을 가로채거나 강제 정지하지 않는다. 진행 표시와 장면별 등장·카메라 동작을 사용한다. 사용자가 회전한 뒤에는 자동 시점 이동이 덮어쓰지 않는다.
- 모바일: 세로 스크롤을 우선한다. 가로로 드래그할 때만 회전하고 기본 페이지 확대·스크롤을 막지 않는다.
- 움직임 줄이기: 자동 시점·입장·색 보간은 즉시 결과로 대체한다. 사용자가 누르는 선택·시점 버튼은 유지한다.
- 그래픽 미지원·로딩 실패·context loss: SVG와 HTML 건물 선택·표 비교를 유지한다.

## 구현 경계

Three.js 0.187.0의 두 공식 브라우저 모듈과 MIT 라이선스를 로컬 `vendor/`에 둔다. CDN·외부 API·빌드 서버를 추가하지 않는다. 새 `scene3d.mjs`는 기존 `update` 계약을 보존하고 시점 메서드를 추가한다. 색 계산은 기존 `city.mjs`의 단일 함수로 공유한다.

렌더는 변경이 있을 때와 짧은 보간 동안만 실행한다. 화면 밖·숨긴 탭·파괴된 장면은 멈추고, 해상도·그림자·재질 개수를 제한한다. 테스트 결과로 기기 성능이나 FPS를 주장하지 않는다.

## 검증

카메라 범위·스크롤 진행·클릭/드래그 구분을 순수 테스트로 확인한다. 실제 브라우저에서 3D 렌더, 드래그와 수직 스크롤, 선택→점수→비교, 수동 시점 보호, 키보드, context loss와 reduced motion을 확인한다. 1440/768/390px 화면과 공개 Pages의 실제 자산·동작을 확인한다.
