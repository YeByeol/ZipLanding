# ZIP 시네마틱 소개 페이지 — Apple 레퍼런스 반영

2026-11-12. 사용자 제공 기준: https://www.apple.com/kr/macbook-pro/proled-xdr-display/ . 사용자가 ‘이런 것처럼, 기존 것을 모두 탈바꿈’이라고 바로잡았다. **직전 split-stage/모바일 고정 본문 안은 폐기한다.** 그 안은 feature branch의 2b5bfbf에 중간 보관했으며 배포하지 않았다. 기존 제작·배포 승인은 지속된다. 제품의 실제 의미·ZIP 이름/로고·예시 계산을 보존하고 페이지의 구성·연출·시각 위계를 전면 교체한다.

## 직접 관찰한 레퍼런스와 차용 범위

Apple 데스크톱1440 및 모바일390을 실제 열람했다. 첫 화면은 하나의 검은 전폭 무대, 중앙의 짧은 문구와 큰 제품, 이후 큰 문구·큰 대상·상세 설명이 다른 박자로 이어진다. 세부 기능 선택 시 대상의 각도/화면과 설명이 함께 바뀌는 것을 확인했다. 표본에서 모든 장면 변화가 스크롤 구동인 것은 확인하지 않았으므로 그 구현을 추정해서 복제하지 않는다. Apple 사진·영상·소스·문구는 사용하지 않는다. ZIP의 도시와 값으로 별도 연출한다.

Taste 주 방향은 사용자 레퍼런스에 따라 `product-performs`로 재지정, palette/type 유지. 이전 split-stage seed848239414는 이 요구와 달라 폐기했다. Impeccable animate의 ‘하나의 주 연출, 상태·관계·위계를 설명하는 동작’을 적용한다. 새 라이브러리·글꼴·테마 설정을 설치하지 않는다.

## 시각 세계

첫 화면부터 **짙은 청록에 가까운 검은 무대(#061D19)**와 밝은 입체 도시, 넓은 여백, 큰 중앙 제목이 등장한다. 기존 밝은 paper(#F4F7F6)는 실제 체험과 비교의 넓은 장면에서 쓴다. 가격 청록/점수 보라의 의미와 Pretendard, 기존 ZIP 벡터 로고는 유지한다. 소개에서 도시 모형을 옆 칸에 작게 넣거나 표·시점 버튼을 나열하지 않는다.

## 전체 시퀀스

### 전폭 소개 무대 — 한 도시의 네 장면

큰 도시 하나가 viewport를 사용한다. 자연스러운 스크롤의 제한 구간(약400svh) 동안 **무대 전체**가 sticky이고, 그 안의 카메라·짧은 문구·값이 함께 바뀐다. 본문만 viewport에 fixed하지 않는다. 무대가 끝나면 도시와 문구가 함께 문서 흐름으로 빠져 체험으로 이어진다. 스크롤 입력을 가로채거나 잠그지 않는다. 모든 장면은 앞뒤 스크롤과 resize에서 같은 위치로 결정된다. phase anchors 4개는 키보드로도 이동한다.

| 장면 | 중심 문구 | 도시와 화면의 변화 | 증거 |
|---|---|---|---|
| 시작 | **당신의 기준으로. / 도시를 새롭게.** | 중앙의 넓은 도시, 청록 가격. 큰 제목 위/대상 아래의 전폭 제품 무대 | ‘장소의 조건과 가격을 함께 읽는 지도 플랫폼’ 한 문장, ‘가상 예시로 체험하기’ 행동 |
| 장소의 안쪽 | **가격표 뒤의 / 조건까지.** | 같은 선택 건물로 카메라가 가까워지고 시점이 낮아짐. 경사 의미의 모래색 | 같은 장소의 경사·고도·연식 3값. 자료 없음은 단위 없이 표시 |
| 나의 시선 | **기준이 바뀌면, / 도시도 달라집니다.** | 다시 도시 전체로 넓어지고 보라색 점수로 이어짐 | 같은 선택 ID의 현재 점수, ‘가격은 점수에 넣지 않습니다’ |
| 가격과 판단 | **조건은 비슷하게. / 가격은 나란히.** | 위에서 읽는 넓은 도시로 전환, 가격 청록 | 선택 장소의 월 환산 단가·±5점 예시 수. 퍼센트 조작 없음, ‘직접 내 기준으로’ 체험 행동 |

장면 본문은 최대 짧은 2문장, 숫자는 한 값 또는 세 조건만 둔다. 비교 장소20개가 있어도 긴 목록을 고정 무대에 출력하지 않는다. 소개의 peer preview가 필요하면 최대3곳+나머지 개수, 전체는 체험의 일반 문서 details 안에서 읽는다. 가격 근처에 가상 예시 표시와 연5% 환산 가정을 알린다.

카메라의 변화는 ‘전체→선택 장소→전체 재색칠→가격 비교’의 의미로 사용한다. 기본 yaw.72/pitch.68/zoom1, 선택 장소 확대 yaw.50/pitch.52/zoom2.3 + 선택 건물 target, 기준 장면 yaw.95/pitch.80/zoom1.05 + 도시중심, 가격 장면 yaw.12/pitch1.08/zoom1.1 + 도시중심. 선택한 장소의 좌표는 기존 buildingPosition을 사용한다. 스크롤 사이 값은 연속 보간하고, 장면별 문구/색 의미는 해당 phase에서 일치한다.

### 넓게 열리는 실제 체험

중앙 제목: **이제, 당신의 / 기준을 움직여보세요.**
큰 도시가 넓은 밝은 무대로 이어지고 아래에 세 중요도가 가로로 놓인다(모바일 세로). 슬라이더→같은 state→재색칠/점수/요약/비교가 연결된다. 가격/내 기준/가격 대비/지형의 기존 실제 주제와 선택·담기·공유는 유지한다. 수동 카메라 조작은 한 details 안에만 제공한다. 선택 장소 요약과 비교로 가는 행동이 체험의 결론이다. 기존 좌우 앱 패널 배치를 그대로 쓰지 않는다.

### 선택 이유를 남기는 비교

중앙 제목: **세 곳의 차이, / 선택할 이유가 됩니다.**
같은 A/B/C 이름표로 가격·점수·조건을 큰 세 열로 비교한다. 마케팅 기능 카드가 아니라 실제 저장한 장소의 비교다. 모바일은 읽을 수 있는 요약 행으로 바꾼다. 상세 표는 펼쳐볼 수 있다. 데이터 전체가 보조기기에도 읽히고, 마지막 제거 후 눈앞의 빈 상태 행동에 focus가 남는다.

### 근거와 마무리

짙은 무대의 큰 문장 **모르는 것은, / 모른다고.** 뒤에 신고·추정·묶음·자료 없음의 짧은 근거를 둔다. 개발 중인 예시이며 첫 범위는 관악 가격/건물/지형, 나머지는 계획임을 설명한다. FAQ는 간결한 읽기 구간이다.

마지막은 **이제, / 당신의 기준으로.** 와 체험으로 돌아가는 행동, 큰 ZIP 워드마크가 화면을 닫는다. 기존 페이지의 작은 반복 섹션·표 우선·상단 조작 나열을 모두 교체한다.

## 상태·DOM·실패 계약

- 두 모형: 비조작 소개 #story-city, 실제 체험 #experience-city. 스크롤은 phase/camera만 바꾸고 제품 weights/selected/saved/mode/URL을 변경하지 않는다.
- 기존 main의 모든 체험/비교/공유 ID와 data-select/data-mode를 유지한다. #platform은 소개 root, #story-stage는 전폭 무대. #story-price/#story-conditions/#story-criteria/#story-value는 4개의 [data-story-step] waypoint다. viewport 중앙 기준으로 현재 phase를 정한다. 카메라 progress는 첫 waypoint의 시작0에서 마지막 waypoint까지0..1로 따로 계산해 첫 화면이 실제 wide frame0이 된다.
- [data-story-panel=price|conditions|criteria|value]가 장면의 짧은 문구와 값을 담는다. 장면이 바뀔 때 하나만 보이고, [data-story-link]로 모든 장에 접근한다. 짧고 제한된 분량을 지키며 내부 중첩 스크롤을 만들지 않는다.
- 기존 data-story-field와 data-story-unit을 재사용하고 missing typography를 유지한다. #story-caption/#story-legend/#hero-selection은 장면의 보조 정보이며 작은 앱 HUD 격자로 첫 화면을 채우지 않는다.
- JS 없을 때는 모든 장의 문구·기본 값이 일반 문서 흐름으로 읽히고 정지 SVG, A/B/C 요약·상세 표가 남는다. JS 초기화 후에만 한 무대 연출을 활성화한다.
- WebGL 미지원은 SVG와 현재 phase의 설명/값을 유지한다. reduced motion은 wide 정지 카메라와 즉각적인 phase 정보·색 전환을 제공한다. 불필요한 자동 움직임·소리·상시 루프 없음.
- 정상390x844도 전폭 한 무대다. 제목/도시/값/phase links가 같은 stage 안에서 viewport를 나눠 사용한다. 낮은 가로 화면에서 공간이 안 나면 일반 흐름으로 바꾼다. 320px/선택X/20 peers도 overflow·자료 없음 깨짐·가려진 CTA가 없어야 한다.

## 성공 기준

첫 화면만 봐도 기존 좌우 설명 페이지와 다른 전폭 제품 소개임이 분명하다. 도시 전체→건물 확대→전체 재색칠의 화면 크기와 시점 차이가 실제로 보인다. 읽고 있는 장의 문구·값·색·카메라가 일치한다. 체험·비교·근거·마무리도 새 위계와 리듬으로 이어진다. 모든 실제 계산과 예시 표시를 유지하며 새 브라우저/접근성/모바일/공개 배포 검증을 한다.
